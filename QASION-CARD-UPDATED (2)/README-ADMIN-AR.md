# لوحة إدارة QASION CARD

الرابط: `http://localhost:3000/admin/`

## التشغيل
1. انسخ `.env.example` إلى `.env` وضع على الأقل: `ADMIN_USERNAME` و`ADMIN_PASSWORD` (قوية، 12 حرف فأكثر).
2. `npm install` ثم `npm run dev`.
3. افتح `/admin/` وادخل.

## أين تُحفظ البيانات؟
ملف واحد `data/store.json` (المنتجات، الطلبات، الإعدادات، الأجهزة، سجل النشاط) مع نسخة احتياطية تلقائية `store.bak.json`.
خذ نسخة من مجلد `data/` دورياً. على Vercel الملفات لا تُحفظ، استخدم استضافة بقرص دائم (VPS أو Render مع Disk).

## إدخال المنتجات يدوياً (بدل المزامنة)
- **منتج واحد:** المنتجات ← «منتج جديد».
- **قائمتك كاملة دفعة واحدة:** المنتجات ← «استيراد»: الصق CSV أو JSON.
  - أعمدة CSV: `name, category, price` (مطلوبة) و`cost, currency, minCount, maxCount, image, note, gameName, active`.
  - الأقسام: games, apps, social, cards, crypto, accounts, ai, payments, software, microsoft, pc, iptv, sites, special, gifts (أو اسم القسم بالعربي).
  - «دمج» يحدّث الموجود بنفس الاسم ويضيف الجديد؛ «استبدال» يمسح اليدوي أولاً (للإدارة الرئيسية).
- «تصدير CSV» يعطيك قائمتك للتعديل في Excel ثم إعادة الاستيراد.

## الطلبات
الزبون لازم يكون مسجّل دخول. السعر يُحسب بالخادم (ما بيقدر الزبون يغيّره). الوضع الافتراضي «مراجعة الإدارة»: الطلب يظهر عندك بحالة قيد المراجعة، تنفّذه (يدوياً أو «إرسال للمزوّد») ثم تغيّر حالته.
> ملاحظة: خصم الرصيد من محفظة الزبون غير مربوط بالطلبات في هذه النسخة، لذلك الوضع التلقائي يصرف من رصيدك عند المزوّد.

## الصلاحيات
- **الإدارة الرئيسية:** كل شيء (حذف، إعدادات، إيداعات، أجهزة، سجل النشاط، إيقاف حسابات، إرسال للمزوّد).
- **الدعم:** منتجات (إضافة/تعديل/مزامنة)، طلبات (تغيير الحالة)، عرض المستخدمين والإعدادات. من جهاز مفعّل فقط.

## الأمان المطبّق
كوكي HttpOnly + SameSite=Strict، قفل 15 دقيقة بعد 5 محاولات فاشلة، حماية CSRF (JSON + Origin)، مقارنة كلمات السر بزمن ثابت، جلسة 8 ساعات، رفع صور بفحص المحتوى (PNG/JPG/WEBP فقط، 3MB)، التحقق من كل المدخلات بالخادم، سجل نشاط لكل عملية.

## فحص شامل
`npm run test:admin` يشغّل 70+ فحصاً تلقائياً على بيانات مؤقتة ولا يلمس بياناتك.
`npm run test:products` يفحص اتصال مزوّدي المنتجات.
