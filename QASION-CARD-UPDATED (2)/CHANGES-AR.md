# تعديلات هذه النسخة
- يوتيوب وواتساب صارا اختياريين (روابط متابعة فقط)، والإجباري الوحيد هو تلغرام (تحقق فعلي عبر البوت) وبيتحكم فيه FORCED_CHANNELS_REQUIRED بـ .env.
- شريط الصور العلوي: 3 صور جديدة (public/assets/banner-*.jpg) بدل الأقصى والأموي، مع نسخ خفيفة للموبايل.
- الشعار الجديد بكل الموقع: site-logo.png (أيقونة شفافة) و site-logo-full.png (للدخول والواجهة الرئيسية) + favicon.
- إضافة أنواع MIME الصحيحة للصور بـ server.js.
- لم يتم لمس منطق جلب المنتجات ومزامنتها.
- المنتجات: لو فشل المزوّد (408 أو fetch failed) ما عاد تنمسح المنتجات الحالية؛ بتضل آخر قائمة حقيقية ناجحة (بالذاكرة وبملف data/products-cache.json).
- إعادة محاولة تلقائية ومهلة 20 ثانية لكل مزوّد (PROVIDER_RETRIES و PROVIDER_TIMEOUT_MS).
- رسالة "لا توجد منتجات" صارت بتوضّح السبب (مفاتيح مزودين ناقصة أو تعذر الاتصال).
- أمر فحص المزودين: npm run test:products (بيبيّن لكل مزود: شغّال، توكن غلط، دومين محجوب، إلخ، بدون طباعة التوكن).
- قراءة .env صارت بتشيل المسافات الزايدة حول القيم (كانت تخرّب التوكن).

## لوحة الإدارة الجديدة (انظر README-ADMIN-AR.md)
- لوحة حقيقية بالكامل: لوحة معلومات، منتجات (إضافة/تعديل/حذف/استيراد CSV-JSON/تصدير/إجراءات جماعية)، طلبات بسجل وحالات، مستخدمون (Supabase)، إيداعات، إعدادات (بنرات، إعلان، صيانة، روابط، تسعير)، مزوّدون، أجهزة الدعم، سجل نشاط.
- حُذفت الأقسام الشكلية القديمة (حقول field_0 بلا وظيفة).
- المنتجات صارت تُدار من اللوحة (تخزين دائم)، والمزوّدون اختياريون.
- الموقع يقرأ البنرات والإعلان والصيانة من اللوحة، ونافذة طلب حقيقية بدل prompt().
- إصلاح: كان أي مسار API بعد /api/admin يطلب تسجيل دخول الإدارة (مثل /api/rates).
- إصلاح: الطلب كان بدون تسجيل دخول وبدون تحقق؛ هلق يتطلب جلسة حقيقية والسعر من الخادم.
